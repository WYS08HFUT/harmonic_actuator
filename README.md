# HA-110 谐波关节模组

一体化无框电机、谐波减速器、交叉滚子轴承与双绝对值编码器同轴集成的机器人关节模组。机身外径 Ø110 mm，输出端安装法兰 Ø118 mm，中心留出 Ø20 mm 走线通孔。

**在线体验：https://wys08hfut.github.io/harmonic_actuator/**

## 产品特点

- **空间**：电机、减速器、轴承与编码器同轴叠进 Ø110 机身，中心 Ø20 mm 通孔可直接走线，减少外部线缆、缩小关节体积。
- **传动**：无框电机直驱波发生器，柔轮 100 齿 / 刚轮 102 齿，齿差 2 齿，基准减速比 50:1；低背隙、高刚性、结构紧凑。
- **控制**：输入端与输出端双绝对值编码器，上电即知关节位置；输出端交叉滚子轴承直接承担弯矩，刚性壳体减小变形。
- **展示**：交互式三维原理页支持拆解、剖切、自动传动与连续减速比调节，并提供带活动齿部放大窗的二维结构图。

## 交互式原理页

打开 [在线页面](https://wys08hfut.github.io/harmonic_actuator/) 后可：

- 拖动底部的 **拆解** 滑块，按装配顺序查看 24 个零件。
- 打开 **剖切**，查看电机、轴承与谐波齿部的内部关系。
- 打开 **传动**（默认自动运行），观察波发生器把柔轮撑成椭圆，柔轮齿逐个进入刚轮齿槽；输入转速与 20–100 的连续减速比均可调。
- 点击 **齿部** 查看轴向齿圈特写，点击 **输出端** 查看输出法兰与交叉滚子轴承。
- 点击 **结构图** 打开二维轴向剖面，并查看右上角实时齿部放大窗；支持滚轮/双指缩放与拖动。
- 点击任意零件查看中文讲解卡；按 `Esc` 关闭，按 `R` 复位。

手机端同样可用：底部为单列控制条，另有可折叠的“为什么这样设计”说明，结构图可缩放。

## 主要参数（演示基准）

| 项目 | 参数 |
|---|---|
| 机身外径 | Ø110 mm |
| 输出端安装法兰 | Ø118 mm |
| 总长 | 122 mm |
| 中心通孔 | Ø20 mm |
| 谐波齿数 | 柔轮 Zf=100 / 刚轮 Zc=102 |
| 基准减速比 | 50:1（页面可演示 20–100） |
| 演示输入转速 | 0–3000 rpm |
| 输出端轴承 | 交叉滚子轴承 RB7013 |
| 编码器 | 输入端 14 位、输出端 19 位，均为绝对值编码 |
| 防护 | 默认 IP40，保留 Ø20 mm 开放通孔 |

> 页面为结构原理演示，传动按 1/20 慢放；尺寸、减速比、转速等数值仅用于展示工作原理，不构成产品性能承诺。最终参数以正式规格书为准。
