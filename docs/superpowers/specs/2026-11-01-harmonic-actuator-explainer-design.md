# 谐波关节模组交互式原理页 · 设计稿

版本：v2 ｜ 2026-11-01（机械架构经专家修订）

## 0. 一句话定位

把一台 Ø110 机身 / Ø118 安装法兰的一体化谐波关节模组做成一个客户可以自己打开、自己看懂的交互式产品原理页：通过**拆开、剖开、转起来**三个动作，回答客户最关心的问题——**这台电机为什么这样设计：内部空间怎么省出来的、动力怎么高效传出去、控制为什么能稳。**

页面是给客户看的科普级产品说明，不是工程图纸，也不是仿真软件。

## 1. 目标与边界

### 1.1 目标

- 客户由销售发链接进入，**不需要讲解**，三分钟内能说出三条设计逻辑：
  1. **空间**：无框电机、谐波减速器、交叉滚子轴承、双绝对值编码器如何同轴塞进 Ø110 机身、Ø118 法兰、122 mm 长度，中间还留 Ø20 走线孔。
  2. **传动**：电机直接驱动波发生器，柔轮 100 齿 / 刚轮 102 齿，固定刚轮时 50:1，低背隙、高刚性。
  3. **控制**：输入端 14 位 + 输出端 19 位绝对值编码器，输出端交叉滚子轴承承担弯矩，刚性壳体减少变形。
- 交互闭环：打开页面 → 拖爆炸滑块 → 点零件看说明 → 开剖切 → 开传动（可调输入转速与减速比）→ 打开二维结构图看齿部啮合 → 复位。
- 减速比连续可调（20:1–100:1，0.5 步进），且**齿形跟着真实齿数重建**。
- 桌面端 60fps、移动端 30fps；4G 下 3D 可用 < 5 s，UI 可操作 < 1 s。
- 只用键盘也能完成核心路径；支持 `prefers-reduced-motion`。

### 1.2 非目标

- 不做热、力、流体或寿命仿真；不承诺真实扭矩/温升数据。
- 不做 CAD 级尺寸测量、BOM 导出、多型号目录。
- 不做账号、收藏、分享、评论。
- 不做展会大屏自动轮播；页面是给单个客户自己看的。
- 不追求照片级写实；优先保证零件可辨认、运动关系正确、啮合看得懂。

### 1.3 反目标（出现即失败）

- 齿形只是贴图或动画，拖减速比时齿数与传动关系对不上。
- 剖切后看不到真正的柔轮—刚轮—波发生器啮合，只看到一团半透明色块。
- 页面必须靠销售在旁边讲解才能看懂。
- 首屏 3D 很漂亮，但手机打不开或卡死。
- 为了“看起来像”，保留会穿模的静态装配。

## 2. 产品叙事

页面不按“零件清单”组织，而按客户的三条疑问组织。每个零件的说明卡都挂回这三条之一。

| 主线 | 客户的问题 | 页面怎么回答 |
|---|---|---|
| 空间 | 为什么能做得这么薄、中间还是空的？ | 爆炸图 + 剖面图展示同轴布局；无框电机直接进壳体、谐波减速器套在输出法兰里、编码器藏在前端/后端盖内。 |
| 传动 | 为什么不用普通齿轮/行星减速器？ | 传动模式：波发生器把柔轮撑成椭圆，100/102 齿差 2 齿，50:1；齿一齿啮合可见。 |
| 控制 | 为什么能稳、能准？ | 输入端编码器负责换相，输出端编码器直接读关节角度；交叉滚子轴承承担弯矩；刚性壳体减少变形。 |

通用命名（可后续替换）：

- 产品名：**谐波关节模组 / Harmonic Joint Actuator**
- 型号：**HA-110**
- 公司名：暂不出现
- 副标题：**一体化无框电机 + 谐波减速 + 双绝对值编码 · Ø110 机身 / Ø118 法兰 · Ø20 空心走线**

性能表述原则：只讲结构原理带来的低背隙/高刚性，不写具体扭矩、转速、精度数值；页面角落标注 **“结构原理示意，最终参数以正式规格书为准”**。多圈位置只在有电子圈数计数时表述为“单圈绝对 + 圈数记忆”，不声称“磁环多圈绝对”。

## 3. 体验与页面结构

### 3.1 整体形态

参考 `AI_design/爆炸视图` 的单屏工具形态，但视觉改为**浅色高级工业风**：

- 全屏 3D canvas，浅暖白背景，柔和棚拍光，金属/阳极氧化质感，接触阴影。
- 顶栏：产品名、型号、副标题；右侧一个“结构图”入口。
- 左侧一段很轻的“为什么这样设计”三条短句，不占大块版面。
- 右侧零件信息卡（点击零件出现）。
- 底部控制条：爆炸滑块 + 镜头按钮 + 传动参数。
- 二维结构图是覆盖在 3D 上的可打开面板，不是新页面。

桌面布局：

```
┌──────────────────────────────────────────────────────┐
│ 谐波关节模组 HA-110          [结构图]                │
│                                                      │
│  为什么这样设计            3D Canvas        ┌───────┐│
│  · 空间                    （浅色棚拍）      │零件卡 ││
│  · 传动                                      │       ││
│  · 控制                                      └───────┘│
│                                                      │
├──────────────────────────────────────────────────────┤
│ [拆解 0–100%]  [剖切] [传动] [复位]  输入 1000 rpm  │
│                                    减速比 50:1      │
│                                    → 输出 20 rpm    │
└──────────────────────────────────────────────────────┘
```

移动端：单列，控制条折叠为底部工具栏，零件卡变底部抽屉，二维面板全屏。

### 3.2 底部控制条

| 控件 | 类型 | 行为 |
|---|---|---|
| 拆解 | 0–100% 滑块 | 逐零件分离，按装配顺序错峰；拖到 >5% 时自动暂停传动/剖切。 |
| 剖切 | 开关 | 全局 180° 切掉前半圈壳体/定子/刚轮，另在谐波段开 90° 局部窗口；不切柔轮、波发生器、输出法兰。 |
| 传动 | 开关（自动运行） | 打开后输入轴/转子/波发生器自动转，输出按减速比转；再点关闭。 |
| 输入转速 | 0–3000 rpm 滑块 | 只在传动开启时显示；数值显示真实 rpm，3D 用慢放系数保证看得清。 |
| 减速比 | 20:1–100:1 滑块，0.5 步进 | 实时重建柔轮/刚轮/波发生器几何；输出转速 = 输入 / 减速比。 |
| 结构图 | 按钮 | 打开二维面板：静态剖面 + 活的齿部放大窗。 |
| 复位 | 按钮 | 关全部镜头、爆炸归零、转速/减速比回默认、相机复位。 |

默认：爆炸 0%，剖切关，传动关，输入 1000 rpm，减速比 50:1。

### 3.3 零件信息卡

点击零件：相机聚焦，其余零件降饱和；右侧滑入卡片。卡片三段式，控制在 40 / 60 / 40 字内：

- **它是什么**：一句大白话。
- **为什么这样设计**：把形状/位置/材料和工程约束连起来。
- **一个反直觉点**：给一个“原来如此”的钩子或失效后果。

每个可点零件都要有文案，不能出现空卡片。零件选择器（隐藏 `<select>`）支持键盘按名称跳转。

### 3.4 镜头组合规则

- 拆解与传动互斥：拖爆炸 >5% 自动暂停传动；开传动自动把爆炸归零。
- 剖切与传动可叠加：传动时壳体/定子/绕组自动半透明，剖切进一步切掉刚轮前半圈。
- 结构图打开时 3D 暂停动画，二维放大窗继续用当前参数动；关闭后恢复。
- 任何时刻最多两个“镜头”同时开启，避免视觉噪音。

## 4. 机械架构（build123d v2，专家修订版）

### 4.1 总体架构

**Ø110 机身 + Ø118 输出端安装法兰**。壳体拆成三段：**后端盖 / 主体 / 输出盖（兼安装法兰）**。原因：Ø92 定子和 Ø100 交叉滚子轴承无法从一端装入一体式壳体；三段式让定子从后方装入、CRB 从输出端装入、后端盖独立承载输入编码器和后轴承。

传动链：

```
无框电机转子 → 空心输入轴 → 波发生器（椭圆）
→ 柔轮 100 齿（椭圆变形）→ 刚轮 102 齿（固定于主体）
→ 柔轮膜片（输出侧）→ 输出法兰 → RB7013 交叉滚子轴承 → 客户负载
```

承载链：

```
客户负载 → 输出法兰 → CRB 内圈 → 滚子 → CRB 外圈 → 主体输出凸台 → 输出盖/安装法兰 → 父级关节
```

### 4.2 外径与安装接口

| 项 | 值 | 说明 |
|---|---|---|
| 机身外径 | Ø110 | 主体与后端盖 |
| 安装法兰外径 | Ø118 | 与输出盖一体，位于输出端 |
| 客户安装孔 | 8×M4 攻丝，PCD Ø96，深 6 mm | 边距 (118−96)/2 − 2.25 = 8.75 mm |
| 客户支架中心让位 | ≥ Ø86 | 输出法兰 Ø82 在其中旋转，留 2 mm 径向间隙 |
| 输出盖—主体螺钉 | 8×M3，PCD Ø110 | 螺帽边距仅 1.25 mm，需在输出盖外缘做 8 个局部凸台/沉台，或降为 M2.5；列为 DFM 待确认 |
| 后端盖—主体螺钉 | 8×M3，PCD Ø100 | 边距 2.25 mm，可接受 |
| 后端盖中心 | 后盖 Ø58，中心通孔 Ø24 | 输入编码器与走线 |

若市场坚持“最大外径 ≤Ø110”，只能做 Ø110 法兰 + 8×M4 PCD88，并把输出盖—主体螺钉降为 M2.5 PCD100；父级支架不能悬出机身。**推荐默认保留 Ø118 法兰，标题写“Ø110 机身 / Ø118 法兰”。**

### 4.5 轴承与支撑

- **输入轴**：前后各一只 6806（30×42×7），跨距 41 mm，夹住 26 mm 电机转子；内圈随输入转，外圈固定。前轴承外圈定位，后轴承外圈浮动 + 波形弹簧，避免过约束。
- **输出**：RB7013（70×100×13）在输出端；外圈压入主体 Ø100 H7/m6，由输出盖筒端面压住；内圈压入输出法兰 Ø70 H7/k6，由 Ø74 轴环和 Z93 台肩双向锁住。
- **波发生器轴承不算第三支撑**：它的内圈随输入、外圈被柔轮约束，作用是让柔轮产生 0.5 mm 径向变形；不能把它当刚性轴支撑预紧，否则会把柔轮过度约束。
- 主体 Ø100 轴承座处壁厚仅 5 mm（Ø110 外 / Ø100 内）；演示模型可用 7075-T6，量产建议钢制轴承衬套或分体钢 cartridge。

### 4.6 编码器

- **输入端**：14 位磁环 Ø46/Ø34×2 固定在转子后端面，PCB 18×12×1.6 装在后端盖腔内，轴向气隙 1.2 mm；拆后盖即可维护。
- **输出端**：19 位磁环 Ø78/Ø74×4 缩配/粘接在输出法兰 Ø74 轴环上，PCB 20×12×1.6 从主体外径径向插入，穿过主体输出凸台与输出盖筒的径向窗，传感器 R40，径向气隙 1.0 mm；2 mm 盖板 + 4×M2 固定。
- **多圈**：磁环本身是单圈绝对；多圈靠电池/超级电容或非易失计数器实现。页面文案写“单圈绝对 + 圈数记忆”，不写“磁环多圈绝对”。
- **双编码器默认保留**：输入端负责 FOC 换相，输出端负责关节绝对角度。若成本优先，可只保留输出端，输入端改无感 FOC；页面相应删掉“双绝对值”表述。

### 4.7 运动学接触 vs 真实配合

**运动学接触（静态干涉检查排除，单独查相切/预紧）：**

### 4.8 与 v1 相比修掉的问题

1. 输出端堆叠反了 → CRB 移到输出端，输出法兰作为 CRB 内圈座，柔轮膜片在输出侧。
2. 输出法兰与刚轮实体重叠 → 输出法兰鼻部在刚轮轴向范围之外，只与柔轮轮毂贴合。
3. 柔轮方向反了 → 齿圈在电机侧，膜片在输出侧。
4. 波发生器与柔轮静态穿模 → 中性 CAD 波发生器缩小到能塞进圆柔轮；工作椭圆只在查看器/2D 教学中出现。
5. 壳体一体无法装配 → 拆成后端盖 / 主体 / 输出盖三段。
6. 输入轴无支撑 → 前后 6806 双轴承。
7. `Hole(depth=10)` 双向切削 → 所有盲孔用显式单向圆柱或 `CounterBoreHole`；8×M3 / 8×M4 / 8×M5 / 销孔全部单向，加工后校验方向。
8. 编码器 PCB 埋进壳体 → 输入端在后盖腔内，输出端从主体外径径向插入。
9. 交叉滚子嵌进平面环 → V 型滚道，滚子相切。
10. 外壳不是单一实体 → 主体、后端盖、输出盖各自为单一实体，装配关系明确。

### 4.9 拆分、装配顺序与 DFM

**拆分：**

- `Rear_End_Bell`（后端盖）承载后轴承、输入编码器、后盖。
- `Body_Housing`（主体）承载定子、前轴承、刚轮、CRB 外圈、输出端编码器窗。
- `Output_Cap_Mount_Flange`（输出盖/安装法兰）压住 CRB 外圈、提供 8×M4 客户安装孔、输出编码器径向窗。

**装配顺序：**

1. 主体 + 前轴承外圈；定子从后方压入 Ø92 孔，靠前腹板定位。
2. 前/后轴承内圈压到转子轴颈；转子/输入轴从后方插入；前轴承内圈进入外圈。
3. 后端盖 + 后轴承外圈套过转子后轴颈；8×M3 固定。
4. 从输出端：柔轮杯插入刚轮，刚轮压入主体 Ø76 孔，Z60 台肩 + Z74 卡簧；波发生器凸轮/滚道/钢球装入柔轮；凸轮与输入轴 6×M3 PCD28 连接。
5. 台架：柔轮轮毂与输出法兰 8×M3 PCD36 + 2×Ø3 销；CRB 内圈压到输出法兰 Ø70 轴颈；整体鼻部朝前从输出端插入。
6. CRB 外圈从输出端压入主体 Ø100 孔，靠 Z93 台肩；装保持架/滚子。
7. 装输出盖（用 Ø3 销与主体编码器窗对位）；8×M3；从主体外径径向插入输出编码器 PCB，调 1.0 mm 气隙；盖板。
8. 装输入端磁环、PCB、后盖，调 1.2 mm 气隙。
9. 跑合、编码器标定、背隙检查。

**DFM 待确认：**

- 输出盖 8×M3 PCD110 的螺帽边距只有 1.25 mm；需在输出盖外缘做局部凸台/沉台，或改 M2.5，或改螺纹压环。
- 主体 Ø100 轴承座壁厚 5 mm；量产建议 7075-T6 或钢制衬套。
- 柔轮杯长 23 mm（齿圈 61–73 + 杯壁 73–84）；标准 CSF-20-100 杯约 25–28 mm，若采购标准件，谐波段会加长 3–6 mm，需从客户法兰厚度或电机长度里扣。
- 柔轮 ID47.05 与工作 WG 长轴 Ø48.05 有 1.0 mm 直径过盈，装配需导向锥 + 弹性扩张；不能按自由滑配建模。
- 输出盖筒 ID86 决定父级支架中心让位 ≥Ø86；不要按 ≥Ø90 设计，否则会切到 8×M4 PCD96 的孔壁。
- 开放式 Ø20 通孔与 IP54 不可兼得：默认 **IP40**；若客户要 IP54，需密封电缆接头并放弃开放通孔，列为产品决策。

## 5. 连续减速比与传动实现

### 5.1 运动学

固定刚轮时：

```
i = Zf / (Zc - Zf)
Zf = 2i, Zc = Zf + 2      （标准双波谐波，齿差 2）
m = rf / i                （保持柔轮分度圆半径 rf = 25 mm 不变）
ω_out = -ω_in / i
```

- 减速比滑块范围 **20:1–100:1**，步进 **0.5:1**；拖动时按 0.5 吸附，保证 Zf、Zc 为整数。
- 默认 50:1：Zf = 100、Zc = 102、m = 0.5。
- 20:1：Zf = 40、Zc = 42、m = 1.25；100:1：Zf = 200、Zc = 202、m = 0.25。
- 输出方向与输入相反；页面明确标注。

### 5.2 旋转组

- **输入组**：`Rotor_Hub`、磁钢、碳纤维护套、输入端磁环、`Wave_Generator_Cam/Balls/Flexible_Race`。绕 Z 轴以 ω_in 旋转。
- **输出组**：`Flexspline_Cup`、`Output_Flange`、CRB 内圈、输出端磁环。以 ω_out = −ω_in / i 旋转。
- **静止组**：后端盖、后盖、主体、定子、绕组、前后 6806 外圈、刚轮、CRB 外圈、两套读头 PCB、输出盖。
- **保持架**：CRB 滚子组以 ω_out / 2 公转（外圈固定）；滚子自转不做。

输入转速滑块 0–3000 rpm，数值显示真实 rpm；3D 动画使用慢放系数（1/20），页面角落标注“演示慢放 ×1/20”。

### 5.3 柔轮椭圆变形（修正版）

柔轮在 CAD 与 GLB 中是圆杯；运行时按当前波发生器相位做径向位移：

```
δ(θ, z) = m · f(z) · cos(2(θ - ψ))
r'(θ, z) = r(θ) + δ(θ, z)
```

- ψ：波发生器长轴在柔轮局部坐标中的角度。
- f(z)：从齿圈端（f=1）到膜片端（f=0）的平滑衰减。
- 长轴处柔轮分度圆半径 = rf + m = 25.5 = rc；短轴处 = rf − m = 24.5。
- 柔轮内壁：长轴 23.525 + 0.5 = 24.025（Ø48.05）；短轴 23.525 − 0.5 = 23.025（Ø46.05）。
- **工作波发生器椭圆：长轴 Ø48.05 / 短轴 Ø46.05**；长轴与柔轮内壁相切，短轴脱开。
- 刚轮固定：齿顶 Ø50.0，齿根孔 Ø52.25；长轴处柔轮齿顶 Ø52.0、刚轮齿根 Ø52.25，径向间隙 0.125 mm；短轴处柔轮齿顶 Ø50.0 与刚轮齿顶同径，但周向错开半个齿距，齿侧脱开。
- 齿形用简化梯形/正弦齿廓，齿顶/齿根留 0.25m 径向间隙与适量侧隙；齿数、相位按 Zf/Zc 生成，保证长轴处柔轮齿落在刚轮齿槽中。
- 变形在渲染层实现（优先顶点着色器；若性能允许用 CPU 顶点更新并重算法线）；不修改 GLB 几何。
- **中性 CAD 状态**：圆柔轮 ID47.05；波发生器长轴 ≤Ø46.65、短轴 ≤Ø44.65，保证 ≥0.2 mm 静态间隙；工作椭圆只在查看器和 2D 教学中使用。

### 5.4 连续减速比下的齿形重建

- GLB 包含 build123d 的 50:1 柔轮/刚轮/波发生器作为几何基准；加载后隐藏这三个节点，替换为程序化版本。
- 程序化生成器使用与 build123d 相同的参数表（rf、ha、hf、壁厚、齿宽、Z 位置），保证 50:1 时与 CAD 基准一致。
- 齿形生成：外齿圈（柔轮）与内齿圈（刚轮）各生成一个封闭环形 BufferGeometry；齿廓沿周向周期函数采样，顶/底面三角化，侧壁连接。
- 波发生器：椭圆凸轮、18 颗钢球、椭圆柔性外圈；长短轴 = 柔轮内壁半径 ± m。
- 减速比变化时在 `input`/`change` 上防抖重建（80–120 ms），重建期间保留上一帧。
- 50:1 时用脚本对比程序化几何与 CAD 的关键半径/齿数，作为验收项。

### 5.5 传动演示的自动播放

- “传动”是开关；打开后自动运行，不需要额外播放按钮。
- 输入转速与减速比随时可调；输出转速读数实时更新。
- 爆炸 >5% 自动暂停传动；回到 0 后恢复上次的传动开关状态。

## 6. 剖切与半透明

### 6.1 剖切

- **全局 180° 剖切**：切掉前半圈壳体、定子、绕组、刚轮，用于讲电机、CRB、Ø20 通孔；不切柔轮、波发生器、输出法兰。
- **谐波段 90° 局部窗口**：只在 Z60–87 的 12 点位置切开主体和刚轮，柔轮和波发生器完整保留；客户可以沿切向看进齿部啮合，不破坏“主角”柔轮。
- 切掉的零件保留实心截面感：`clippingPlanes` + 背面材质/双面渲染，避免空壳。
- 剖切后仍能看到：电机段、输入轴、柔轮杯、刚轮齿、波发生器、输出轴承、输出法兰。
- 不切柔轮齿部是刻意的：把柔轮切开会切掉要展示的齿。

### 6.2 半透明

- 打开传动时，壳体/定子/绕组/刚轮自动半透明（opacity 0.15–0.25，`depthWrite=false`），柔轮/波发生器/输出法兰保持不透明。
- 半透明是“透视”，不是“消失”：客户仍能辨认外壳轮廓和安装法兰。
- “只看传动”快捷视角：沿 Z 轴俯视齿圈，壳体/定子完全隐藏，只留刚轮、柔轮、波发生器与输出法兰。

### 6.3 相机预设

- 整机等轴测。
- 齿部特写（沿 Z 轴俯视，略偏 10–15°），从 90° 局部窗口看进去。
- 输出端特写（看 CRB 与输出法兰）。
- 点击零件自动聚焦；Esc 退出。

- 节点名必须与 GLB 一致；导出后校验节点存在、名称唯一、偏移单位正确。

### 8.4 性能与可访问性

- GLB 目标 ≤ 6 MB（Meshopt 后）；UI 可操作 < 1 s；3D 可用 < 5 s（4G）。
- `pixelRatio = min(devicePixelRatio, 2)`；关闭实时阴影，使用接触阴影贴片；不启用后处理。
- 程序化齿形三角面预算 ≤ 40k；柔轮变形顶点更新 ≤ 15k/帧；移动端降采样。
- 键盘：Tab/Shift+Tab 选零件，方向键旋转，+/- 缩放，Esc 取消/关闭面板，R 复位。
- `prefers-reduced-motion`：关闭自动旋转、传动自动运行改为分档（关/50%/100%），二维放大窗静止。

## 9. 验收标准

### 9.1 CAD

- 包络：最大 Ø118（安装法兰），机身 Ø110，总长 122 ± 1 mm。
- Ø20 通孔从后盖到输出法兰全程无遮挡。
- 非运动学接触（定子—主体、绕组—定子、磁钢—护套、法兰—CRB 内圈、CS—主体、轴承—座等）干涉体积为 0；柔轮—刚轮、滚子—滚道、钢球—滚道、WG 外圈—柔轮内壁列为运动学接触，单独检查相切/预紧。
- 输出法兰与刚轮无实体重叠；柔轮膜片与输出法兰贴合；输入轴与柔轮/输出法兰不碰。
- 主体、后端盖、输出盖各自为单一实体；所有盲孔单向钻削。
- CRB 从输出端装入路径无小于 Ø100 的障碍；定子从后端装入路径无小于 Ø92 的障碍。
- GLB 节点名、材质、颜色正确；50:1 基准下程序化齿形与 CAD 关键半径一致。

### 9.2 传动

- 减速比 20/30/50/75/100 时，Zf/Zc 为整数，输出转速 = 输入 / 减速比。
- 3D 截图检查：长轴处柔轮齿进入刚轮齿槽，短轴处脱开；无可见穿模。
- 齿部放大窗与 3D 的相位/减速比同步；50:1 标注正确。
- 输入 0 rpm 时全部静止；传动开关关闭后无残留运动。

### 9.3 页面

- 首屏加载、爆炸 0/100%、剖切开、传动 50:1、传动 30:1、结构图打开六种状态截图通过。
- 所有零件可点击、有文案；悬停高亮；Esc/复位可用。
- 手机宽度 390 px 下控制条可操作，信息卡不遮 3D 主体；结构图可缩放。
- 键盘可完成“爆炸 → 选零件 → 开传动 → 打开结构图 → 复位”。
- GLB 加载失败有错误提示；性能与可访问性不低于参考页。

## 10. 默认决定（专家建议，等待最终确认）

1. **外径口径**：Ø110 机身 / Ø118 输出端安装法兰，8×M4 PCD96。若坚持 ≤Ø110，改 8×M4 PCD88，输出盖—主体螺钉降 M2.5，父级支架不能悬出机身。
2. **安装面位置**：输出端（负载路径最短）。若改后端盖安装，外观和负载路径都会变。
3. **编码器**：双绝对值，输入端 14 位 + 输出端 19 位；多圈靠电子计数。若成本优先，只保留输出端，输入端改无感 FOC。
4. **防护**：默认 IP40，保留 Ø20 开放通孔；IP54 需密封电缆接头并放弃开放通孔。
5. **性能表述**：只讲结构原理带来的低背隙/高刚性，不写扭矩、转速、精度数值；页面加“结构原理示意，最终参数以正式规格书为准”。
6. **减速比范围**：20–100，0.5 步进；Zf = 2i，Zc = Zf + 2；模数随比例变，柔轮分度圆半径固定 25 mm。
7. **输入转速**：0–3000 rpm，3D 用 1/20 慢放。
8. **程序化柔轮/刚轮/波发生器**替换 GLB 中固定 50:1 的三组节点；build123d 仍是 50:1 的几何基准与二维剖面的来源。
9. **剖切**：全局 180° + 谐波段 90° 局部窗口；不切柔轮；齿部啮合主要靠俯视特写和 2D 放大窗。
10. **2D 剖面**：客户页用 teaching composition（齿部变形啮合）；另出中性 CAD 剖面供 QA。
11. **不部署**：先本地开发与生产构建；部署方式等页面验收后再定。
12. **旧脚本保留为模板**，新链路在 `cad/` + `web/`；旧 README 的资产清单在本次同步更新。

## 11. 风险与假设

- 没有扭矩/转速数据：电机按 Ø92 定子、26 mm 有效长度、20 极、0.9 mm 气隙估算；输出扭矩能力未验证，页面不发布具体数值。
- 柔轮杯长 23 mm 比标准 CSF-20-100（约 25–28 mm）短；若采购标准件，谐波段会加长 3–6 mm。
- 主体 Ø100 轴承座壁厚 5 mm；量产需 7075-T6 或钢制衬套/分体 cartridge。
- 输出盖 8×M3 PCD110 螺帽边距 1.25 mm；需局部凸台/沉台或改 M2.5。
- 柔轮 ID47.05 与工作 WG 长轴 Ø48.05 有 1.0 mm 直径过盈；装配需导向锥 + 弹性扩张。
- Ø20 通孔是几何通道，不是密封/静止通道；输入轴和输出法兰都在转，穿线需预留服务环、滑环或静止衬套。
- 多圈位置需要电池/超级电容或 NVM 圈数计数；磁环本身单圈绝对。
- 热、润滑、轴承寿命、结构 FEA 未做；5 mm CRB 壁、0.85 mm 柔轮杯、8×M3 输出盖连接是首批复核项。
- 3D 查看器与 CAD 状态不同：CAD/STEP 是中性零件；查看器做柔轮椭圆变形；静态干涉检查不能直接用查看器截图代替。
